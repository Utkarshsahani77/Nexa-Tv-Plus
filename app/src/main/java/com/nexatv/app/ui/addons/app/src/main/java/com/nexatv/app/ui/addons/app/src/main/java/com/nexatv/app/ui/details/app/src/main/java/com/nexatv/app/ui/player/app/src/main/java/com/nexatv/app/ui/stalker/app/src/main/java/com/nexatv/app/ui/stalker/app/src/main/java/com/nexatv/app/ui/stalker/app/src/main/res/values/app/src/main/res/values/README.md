# NexaTV

NexaTV is a modern Android TV streaming app built with Kotlin and Jetpack Compose.

## Features

- Home
- Live TV
- Movies
- Series
- Search
- Library
- Settings
- Stremio Addons
- Stalker Portal
- HLS Player
- Downloads

## Build

1. Open project in Android Studio
2. Sync Gradle
3. Run app
4. Or use GitHub Actions to build APK

## GitHub Actions

- Go to Actions tab
- Run Android CI
- Download APK artifact
